### 📌 Featured project

#### [Will It Get Built? Predicting Which Housing Element Sites Are Realized](https://github.com/JohanArisato/housing-site-realization)
California cities list thousands of parcels as able to hold new homes. Which of San Diego's 2021 inventory sites actually received housing approvals, and can a spatially validated model predict that better than the city's own capacity assumptions?

- Leak-free design: features frozen at the 2021 inventory, outcome measured afterward, enforced by tests
- Spatial cross-validation by community plan area, calibrated probabilities, bootstrap confidence intervals
- Planner outputs: realistic capacity per community, an equity audit across state opportunity areas, an interactive map

`Python` `GeoPandas` `scikit-learn` `LightGBM` `SHAP` `Folium` `ArcGIS REST`
